# README.md Maintenance Rule

Whenever any feature, fix, database change, or frontend component is added or modified in `crm.fsadvisory.ae`:
1. You must proactively update `README.md` to reflect the change.
2. Update the implemented modules numbering and bullet points.
3. Update the directory structure tree if new files or components were introduced.
4. Verify that non-negotiable domain rules remain intact.
5. NEVER execute `git push` without explicit user instruction.
